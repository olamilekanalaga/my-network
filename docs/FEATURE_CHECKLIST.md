# Feature checklist

“Implemented” means code and an interactive path exist. It does not mean a third-party provider was exercised without credentials. “Demo-only” means browser-local fictional behaviour. “Not implemented” means no working integration is claimed.

| Area                          | Status                           | Concrete behaviour / boundary                                                                                                                                           |
| ----------------------------- | -------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Five-section navigation       | Implemented                      | Home, People, Network, Opportunities, Profile/Settings; responsive sidebar/bottom tabs                                                                                  |
| Fictional demo                | Demo-only                        | 10 people; UK/African Web3, construction, property, printing, events, fintech, investing, software and customers; persistent browser edits                              |
| Sign up / in / out            | Implemented, provider-unverified | Supabase email/password UI and verified-user API; requires Supabase setup                                                                                               |
| User isolation                | Implemented, SQL-tested          | RLS on every user-owned table, owner-set writes, composite owner FKs, anonymous denial                                                                                  |
| People CRUD                   | Implemented                      | Rich editor, delete cascade, search, categories, source, verification, relationship strength                                                                            |
| Profile photo                 | Implemented, limited             | User-supplied HTTP(S) photo URL; no upload/storage pipeline                                                                                                             |
| CSV/VCF import                | Implemented, unit-tested         | File parsing, preview, individual/all selection, non-destructive merge or duplicate skip                                                                                |
| Individual/bulk editing       | Implemented, limited             | Individual full editor; bulk category addition to selected contacts. Other bulk field edits are not included                                                            |
| Google Contacts               | Implemented, provider-unverified | Google OAuth + People API, read-only scope, selection preview, memory-only provider token adapter; reconnect after reload                                               |
| Device contact picker         | Implemented, device-unverified   | Uses supported browser picker; explicit CSV/VCF fallback. No claim of iPhone Safari support                                                                             |
| Post-import enrichment        | Implemented                      | Saved basic profiles, separate Add context step, socials/links and notes                                                                                                |
| Many categories               | Implemented, tested              | Customer/supplier/founder/investor/friend etc. simultaneously                                                                                                           |
| Companies/communities/events  | Implemented                      | Create/view/edit/delete; roles via many-to-many affiliations                                                                                                            |
| Person/company relationships  | Implemented, SQL-tested          | Person↔person, person↔company, company↔company, person↔community endpoints and source/status                                                                            |
| Relationship graph/path       | Implemented, tested              | Bounded BFS + recursive SQL function; confirmed edges only; no inferred co-membership introductions                                                                     |
| Capabilities/needs ontology   | Not implemented                  | Text/skill fields retrieved across profiles/orgs; no separate capability/need node ontology                                                                             |
| Customer directory            | Implemented                      | Dedicated Customers filter with purchase records and what they sell                                                                                                     |
| Transaction history           | Implemented                      | Add/delete receipts and payments, currency/date, notes. Corrections use delete/re-entry, not a dedicated edit form                                                      |
| Professional links            | Implemented                      | Attach/open HTTP(S) LinkedIn/X/web/GitHub links; no scraping                                                                                                            |
| Public fact review            | Implemented                      | Paste public text, source URL, observation date; pending → explicit approve; confidence and visibility                                                                  |
| Automated public enrichment   | Not implemented                  | No social API retrieval, arbitrary URL fetching, AI extraction or unauthorised scraping                                                                                 |
| Voice-note transcripts        | Implemented, text input          | Paste transcript into a profile                                                                                                                                         |
| Audio recording/transcription | Not implemented                  | No microphone or audio processing                                                                                                                                       |
| Demo assistant                | Demo-only, tested                | Deterministic lexical retrieval + graph reasoning/evidence templates; no fake API calls                                                                                 |
| Connected OpenAI assistant    | Implemented, provider-unverified | Verified-owner retrieval + Responses strict schema; unknown person IDs reject output; generated prose marked hypothesis                                                 |
| Evidence attribution          | Implemented, tested              | Saved text and source IDs attached programmatically; pending facts excluded; private notes opt-in                                                                       |
| Coalition discovery           | Implemented, limited             | Ranked complementary candidates, participant needs/contributions, problem, payer/demand/arrangement/risks; heuristic, not an optimiser                                  |
| Opportunity pipeline          | Implemented                      | All eight requested stages, multi-participant/org links, nullable values/fees, dates, notes, outcome                                                                    |
| Introduction tracking         | Implemented                      | Requested/introduced pipeline states; no automatic messaging                                                                                                            |
| Reminders/follow-ups          | Implemented                      | In-app task list, dates, completion/history; no email/push/background scheduling                                                                                        |
| Privacy classification        | Implemented                      | Private notes; private/public/shareable atomic facts; no public profiles                                                                                                |
| Exports/restore               | Implemented                      | Full JSON private backup; approved shareable facts export; version-1 backup merge/restore                                                                               |
| Contact deletion              | Implemented, tested              | Deletes dependent facts/transactions/associations/edges; cleans participant IDs; free-text history needs separate review                                                |
| Account deletion              | Not implemented                  | Clear records in UI; account removal through Supabase admin                                                                                                             |
| PWA                           | Not implemented                  | Mobile web app ready for later manifest/service worker work                                                                                                             |
| Mobile interface              | Implemented, visually unverified | Responsive CSS and actual 380px interactive iframe preview; browser QA blocked by environment                                                                           |
| Production hardening          | Partial                          | Owner policies, authentication, server secrets, validation, safe rendered text/links, bounded requests; no distributed rate limits, audit trail or full security review |
| Deployment                    | Private static demo              | Same interactive UI in browser-local demo mode. Full Next server deployment requires a Next-compatible host and your credentials                                        |
